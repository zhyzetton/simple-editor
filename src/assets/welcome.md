这是一个用 **Tauri + React + Tiptap** 构建的本地 Markdown 编辑器。打开一个文件夹，它就成了你的工作区；文件会原样保存在磁盘上。

## 现在的打开方式

- 左侧是真实的文件树，可以展开文件夹
- 顶部「打开文件夹」可以切换工作区
- 「打开文件」可以打开工作区之外的 Markdown 文件
- 文件名就是文档标题，修改标题会同步重命名文件

> 不写入数据库，也不偷偷加 frontmatter。文件仍然是普通的 `.md`。

### 表格

| 操作 | 方式 |
| --- | --- |
| 新建文件 | 左侧文件树顶部的按钮 |
| 在文件夹中新建 | 右键文件夹 |
| 重命名 | 修改文档上方的标题 |
| 插入命令 | 输入 `/` |
| 引用其他文件 | 写 `[名称](相对路径.md)`，按住 Ctrl/Cmd 点击 |
| 预览打开 | 单击文件：斜体标签只是预览，再单击别的文件会顶替它 |
| 固定标签 | 双击文件打开；在预览标签里改一个字也会自动固定 |
| 切换 / 关闭标签 | Ctrl/Cmd + Tab 切换，Ctrl/Cmd + W 关闭 |

相对路径按当前文件所在目录解析，指向工作区外的 Markdown 会作为外部文件打开。
